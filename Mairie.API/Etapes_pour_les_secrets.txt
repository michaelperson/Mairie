1) Installation du package NuGet DPAPI :
   Ouvrez le terminal ou l'invite de commande.
   Naviguez jusqu'au répertoire du projet Mairie.API en utilisant la commande `cd` suivie du chemin du répertoire.
   Exécutez la commande suivante pour installer le package DPAPI :
   ```
   dotnet add package DPAPI
   ```
2) Création d'une classe utilitaire pour la gestion des secrets :
   Créez une nouvelle classe dans votre projet, par exemple `SecretManager.cs`, et ajoutez le code suivant pour chiffrer et déchiffrer les secrets en utilisant DPAPI :
   ```csharp
   using System;
   using System.Text;
   using DPAPI;
   public static class SecretManager
   {
	   public static string Encrypt(string plainText)
	   {
		   byte[] plainBytes = Encoding.UTF8.GetBytes(plainText);
		   byte[] encryptedBytes = ProtectedData.Protect(plainBytes, null, DataProtectionScope.CurrentUser);
		   return Convert.ToBase64String(encryptedBytes);
	   }
	   public static string Decrypt(string encryptedText)
	   {
		   byte[] encryptedBytes = Convert.FromBase64String(encryptedText);
		   byte[] plainBytes = ProtectedData.Unprotect(encryptedBytes, null, DataProtectionScope.CurrentUser);
		   return Encoding.UTF8.GetString(plainBytes);
	   }
   }
   ```
3) Ajouter dans program.cs un code temporaire pour chiffrer les secrets :
   Ouvrez le fichier `Program.cs` et ajoutez le code suivant pour chiffrer vos secrets. Remplacez `<YourSecretValue>` par la valeur réelle du secret que vous souhaitez chiffrer.
   ```csharp
   string secretValue = "<YourSecretValue>";
   string encryptedSecret = SecretManager.Encrypt(secretValue);
   Console.WriteLine($"Encrypted Secret: {encryptedSecret}");
   ```
   Exécutez l'application une fois pour obtenir la valeur chiffrée, puis supprimez ce code temporaire de `Program.cs`.
4) Ouvrir le terminal ou l'invite de commande.
5) Naviguer jusqu'au répertoire du projet Mairie.API en utilisant la commande `cd` suivie du chemin du répertoire.
6) Exécuter la commande suivante pour ajouter un secret utilisateur :
   ```
   dotnet user-secrets init
   ```
7) Pour ajouter un secret, utilisez la commande suivante en remplaçant `<Key>` par le nom de la clé et `<Value>` par la valeur du secret :
   ```
   dotnet user-secrets set  "<Key>" "<Value>"
   ```
